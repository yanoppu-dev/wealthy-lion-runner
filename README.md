# ウェイッ！小金持ちランナー

**プロジェクト分類：ブラウザゲーム制作**

ライオンが毒キノコなどの障害物を避け、コインを集めるHTMLゲームです。

## 現行版と使い方

- ソース：[claude-runner.html](claude-runner.html)（mainブランチ）
- スペースキーまたは画面タップでスタート・ジャンプ。二段ジャンプができます。
- HTMLファイルを保存し、ブラウザーで開きます。追加のインストールは不要です。
- ハイスコアは利用しているブラウザーに保存されます。
- 配信サイトの公開版との一致や動作確認は別途確認します。
